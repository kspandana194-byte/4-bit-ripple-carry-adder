4-bit Ripple Carry Adder

Description

A 4-bit Ripple Carry Adder is a digital circuit used to add two 4-bit binary numbers. It is constructed using four full adders, where the carry output of each full adder is connected to the carry input of the next stage.

Objective

- Design a 4-bit Ripple Carry Adder using Verilog HDL.
- Verify the design using a testbench.
- Perform simulation and observe the output waveform.

Inputs and Outputs

Inputs

- "A[3:0]" – First 4-bit binary number
- "B[3:0]" – Second 4-bit binary number
- "Cin" – Initial carry input

Outputs

- "Sum[3:0]" – 4-bit sum
- "Cout" – Final carry output

Working

The four full adders are connected in cascade. The carry generated by one full adder becomes the input carry of the next full adder.

A0 ──┐
B0 ──┤ FA0 ── S0
Cin ─┘  │
        C1
        ↓
A1 ──┐
B1 ──┤ FA1 ── S1
C1 ──┘  │
        C2
        ↓
A2 ──┐
B2 ──┤ FA2 ── S2
C2 ──┘  │
        C3
        ↓
A3 ──┐
B3 ──┤ FA3 ── S3
C3 ──┘  │
       Cout

 Tools Used

- Verilog HDL
- Icarus Verilog / ModelSim / Vivado
- GTKWave for waveform visualization
- GitHub

Example

For:

"A = 0101"
"B = 0011"
"Cin = 0"

The result is:

"Sum = 1000"
"Cout = 0"

Therefore:

"0101 + 0011 = 1000"

Verification

The testbench applies different combinations of inputs and checks the resulting sum and carry output.

 Conclusion

The 4-bit Ripple Carry Adder successfully performs binary addition using four cascaded full adders. The design can be simulated to verify its functionality.
